# תיקיית עיצוב — ריקה בכוונה (BLOCKERS.md #1)

הבריף (`docs/PROJECT-BRIEF.md`) מפנה לעיצוב קיים בתיקייה, אבל התיקייה הזו
ריקה בריפו נכון להיום. זהו חסם #1 ב-`docs/BLOCKERS.md`.

## מה קורה עד שהעיצוב מגיע

השכבה הטכנית ב-`site/` נבנתה **אגנוסטית לעיצוב**:

- כל הצבעים/גדלים/מרווחים מגיעים ממשתני CSS יחידים ב-`src/styles/tokens.css`.
- המבנה הסמנטי (קומפוננטות ב-`src/components/`, layout ב-`src/layouts/`)
  לא תלוי בעיצוב ספציפי — הוא HTML נקי + slots.
- שום דימוי/גופן/אייקון סופי לא "מנוחש" בקוד. מקום מוקצה עם placeholder
  מסומן (`data-placeholder="design-pending"`).

## מה עושים כשהעיצוב מגיע

1. שמים את נכסי העיצוב (תמונות/אייקונים/פונטים) בתיקייה הזו
   (`site/public/design/...`).
2. מעדכנים את `src/styles/tokens.css` עם הצבעים/הטיפוגרפיה הסופיים.
3. מחליפים את ה-`hero__media` placeholder ב-`src/components/Hero.astro`
   בתמונה/וידאו האמיתיים.

**אין צורך לבנות מחדש קומפוננטה או routing** — זו בדיוק המשמעות של
"אגנוסטי לעיצוב" (ראה `docs/ARCHITECTURE.md`).
